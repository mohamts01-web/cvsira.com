# إلمام CV — Anchor

التحديث الحالي يضيف وضعًا أسود معتمًا ووضعًا أبيض مع حفظ الاختيار، ومكونات EldoraUI المكيّفة مع العربية. تفاصيل المواضع والتكييف والترخيص في [docs-eldoraui.md](docs-eldoraui.md).

نسخة واجهة مستقلة تعتمد قالب المستخدم Anchor لغةً موحّدة لجميع الصفحات. تنظيم محادثة المساعد والكرة النقطية مستمدان من Ai-1، بألوان Anchor.

## التشغيل

React + TypeScript + Vite. استخدم Node.js و pnpm، ثم:

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm test
```

متغيرات الاتصال بالخدمات الحالية هي `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` و`VITE_ETMAM_API_URL`. لا تضع مفاتيح خدمة سرية في متغيرات الواجهة.

## الصفحات

- الرئيسية: العرض المتسلسل، شبكة Anchor، البطاقات، خطوات الرحلة، القوالب، عرض التقديم، والأسئلة.
- /documents: لوحة الخدمات والمسودات والرصيد واستئناف العمل.
- /assistant: مساعد مستقل مع اختيار المسودة، الاستيراد والتحسين والترجمة، ومراجعة التغييرات.
- /tools/jobs و /tools/interviews و /tools/applications و /tools/linkedin: الخدمات الحالية.
- /start و /try و /editor/:id: الإنشاء والمحرر المباشر والقوالب والتصدير.
- /plans والسياسات: نفس هوية Anchor مع إبقاء قواعد الشراء الحالية.

## حدود المعاينة

المعاينة المستقلة تستخدم بيانات وهمية فقط وطبقة خدمة محلية داخل المتصفح. النتائج التي تظهر فيها تجريبية، ولا تثبت تنفيذ نموذج AI حقيقي أو دفعًا أو دخولًا فعليًا. ملف PDF التجريبي مُنشأ من بيانات اصطناعية، وليس ملف عميل. الفهرسة والإحصاءات الإنتاجية معطلة.

نشر المعاينة من `scripts/deploy-preview.ps1` محصور في موقع Netlify المستقل، ويقرأ رمز الدخول الخاص من الملف المحلي دون تضمينه في الحزمة.

لم تنفذ ترحيلات قواعد بيانات أو تغييرات على البوت أو خوادم الإنتاج ضمن هذا التصميم. يلزم فحص الاتصال الحقيقي بحساب اختبار قبل نقل النسخة إلى الدومين الفعلي.

## التحقق

تم الاحتفاظ باختبارات البيانات والتنسيق والتحقق من الدفع والخصوصية، وتحديث اختبارات الهوية لتتحقق من عناصر Anchor الجديدة وإتاحة التنقل وتباين النصوص. ألوان ورقة السيرة تبقى منفصلة عن واجهة الموقع الداكنة لضمان وضوح التصدير والطباعة.
