# تنفيذ المرحلتين الثالثة والرابعة

نسخة المعاينة بتاريخ 20 نوفمبر 2026.

## المكونات الفعلية

تم جلب المصادر الرسمية من magicui.design/r وحفظ ترخيص MIT في src/components/magicui/LICENSE.md. يستخدم التنفيذ MagicCard وNumberTicker وBlurFade وAnimatedBeam وAnimatedCircularProgressBar وDotPattern وBorderBeam.

التكييف يشمل توحيد motion/react مع framer-motion الموجود، وألوان theme-tokens، وتنسيق الأرقام العربية، وreduced-motion، وحدود مقياس الرصيد عندما يكون الحد صفرًا، وتعطيل تتبع المؤشر عند اللمس. يستخدم CareerFlow إيقافًا يدويًا وتتبع ظهور المشهد وحالة التبويب.

## المرحلة الثالثة

| الجزء | التنفيذ |
| --- | --- |
| النظرة العامة | NumberTicker للمؤشرات، مقياس الرصيد الرسمي، MagicCard للخدمات، جدول السير الحالي وإجراءاته |
| المساعد | استبدال مشهد الكرة بـCareerFlow، اختيار المسودة والمحادثة والمراجعة الحالية، أسطح وحقول موحدة |
| القائمة | مقاسات الرأس والقائمة مشتركة عبر متغيرات، ارتفاع مرتبط بالشاشة وتمرير داخلي، تسميات الخدمات الحالية |
| التحويل اللوني | ThemeProvider الحالي مع View Transitions عند دعمها، وتحويل مباشر عند تقليل الحركة أو غياب الدعم |

## المرحلة الرابعة

| الصفحة | التنفيذ |
| --- | --- |
| الرئيسية | MagicHero ومشهد المنتج وحد متحرك وتدفق السيرة والوظيفة، خدمات MagicCard، توحيد الأقسام والقوالب والأسئلة |
| الدخول والحساب | مظهر الحوار والحقول والأزرار والتركيز موحد، مع بقاء مسار OTP والربط والعضوية |
| الباقات | توحيد مظهر العرض والبطاقة والزر، مع إبقاء بيانات العرض ومسار Whop الحالي |
| الإنشاء | بطاقات الحالات المهنية، تقدم الخطوات، الاستيراد، حقول وإجراءات متسقة |
| المكتبة | تنسيق البطاقات والفلاتر وأزرارها، مع إبقاء الفتح والحذف واختيار نسخة الوظيفة |
| المحرر | رأس وأدوات وحقول وتنزيل موحدة، وورقة السيرة مستقلة عن مظهر التطبيق |
| مراجعة الاقتراح | تبويبات وأقسام ومقارنة وتذييل إجراءات بهوية مشتركة |
| السياسات والأدلة | أسطح قراءة وخط Tajawal محلي وأزرار ومقاسات متسقة |

تستورد main.tsx ملف النظام الجديد في نهاية سلسلة الأنماط ليكون مرجع التخصيص الحالي. تظل إزالة طبقات التنسيق القديمة بعد نقل جميع مستهلكيها مهمة صيانة مستقلة ضمن الإنهاء العام.

## أدلة التحقق

- نجح TypeScript دون أخطاء.
- نجحت الاختبارات الـ69 بعد تعديل فحص هوية الواجهة ليرتبط بالنظام الجديد ومشهد CareerFlow.
- فحص عرض الجوال عند 390px شمل الرئيسية والنظرة العامة والمكتبة والمساعد والباقات والإنشاء والمحرر التجريبي والسياسات والتواصل ودليل ATS. جميعها دون تجاوز أفقي للصفحة.
- فحص الوضع الفاتح على الجوال شمل الرئيسية والنظرة العامة والمساعد والباقات والإنشاء والمحرر والتواصل دون تجاوز أفقي.
- تحقق الانتقال من الحالة المهنية إلى الوظيفة المستهدفة.
- تحقق فتح محرر المسودة وقائمة تنزيل PDF وWord.
- تحقق اختيار مسودة في المساعد ثم عرض نتيجة تحسين تجريبية ومقارنة الأصل والمقترح.
- تحقق فتح حوار الباقة والحساب وظهور إجراءات الربط.
- تحقق بقاء القائمة والمساعد داخل الارتفاع المتاح عند تصغير العرض.

تستخدم المعاينة /mock وخدمات وهمية ومحتوى tester@example.invalid. نتائج هذه الجولة تخص الواجهة والخدمات التجريبية. التحقق من دفع حقيقي أو إرسال بريد أو توليد PDF من الخدمات الحية يتبع اختبار الإطلاق.

أوقفت المراجعة الآلية محاولة اعتماد قرار «الاحتفاظ بالأصل». اكتفينا بإغلاق المراجعة وفحص عرض المقارنة. اختبار التحسين التجريبي استؤنف بعد إثبات أن الاستجابة محلية من /mock.

المرحلة الخامسة تخص إعادة تصميم أدوات الوظائف والمقابلات والتقديم وLinkedIn تفصيليًا. أخذت هذه الصفحات أساس النظام المشترك الحالي، وتبقى هياكل الأدوات التفصيلية لدورتها المخصصة.
