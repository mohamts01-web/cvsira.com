# خريطة مراجع Magic UI

هذه خريطة اختيار للمرجع الذي أرسله المستخدم. «أساسي» يعني مرشحًا لنموذج المرحلة الثالثة. «اختياري» يعني أن إدراجه يعتمد على نجاحه بصريًا وعلى تكلفته. تتطلب جميع المكونات فحص الكود الفعلي والترخيص والتبعيات قبل النقل. تصنيف المراجع وحده لا يثبت اختبار تشغيلها.

## مكونات النموذج الأساسي

| المكون | الموضع والدور | تكييف إلمام |
| --- | --- | --- |
| Magic Card | بطاقات الخدمات | لون موحد، حالة focus ظاهرة، بديل لمس ثابت |
| Animated Circular Progress Bar | رصيد المساعد | قيمة وحصة فعلية، تسمية عدد العمليات، معالجة الحد صفر |
| Number Ticker | أرقام المسودات والرصيد | تنسيق ar-SA، القيمة الأخيرة المؤكدة، reduced-motion |
| Blur Fade | دخول الأقسام | مرة واحدة، زمن قصير، بقاء المحتوى متاحًا |
| Animated Beam | شرح تخصيص السيرة | ربط السيرة والوظيفة والمراجعة، تكيف RTL وحجم الحاوية |
| Bento Grid | ترتيب الخدمات والرئيسية | أولوية مهام المستخدم، أعمدة تتكيف مع المساحة |
| Theme Toggler | تحويل الوضع العام | توصيله بحالة ThemeProvider نفسها وإبقاء الاختيار محفوظًا |
| Text Animate | عناوين المشاهد | حركة بالكلمات أو النص الكامل في العربية |
| Shimmer Button | دعوة الإنشاء الرئيسية | حالة تركيز وتحميل وتعطيل مشتركة مع بقية الأزرار |
| Dot Pattern | خلفية مشهد مخصص | كثافة منخفضة، طبقة لا تلتقط النقرات |

## تكامل متوقع

يستخدم المشروع سجل shadcn في components.json. إضافة @magicui إلى السجلات مقترحة عند بدء المرحلة الثالثة، ثم إضافة المكونات المختارة تدريجيًا. يتيح [التوثيق](https://magicui.design/docs/mcp) استخدام سجل Magic UI عبر MCP الخاص بـshadcn.

لكل مكون مُدمج لاحقًا يسجل اسم الملف، وإصدار أو تاريخ المصدر، والترخيص، والتكييف العربي، والتبعيات، ونتيجة فحص الهاتف والحركة المخفضة. تُحسم البدائل في النموذج ويصبح لكل دور مكوّن معتمد واحد.
